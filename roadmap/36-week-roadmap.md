# 48 周 AI 全栈系统开发路线

> 目标：在持续实践和阶段验收的前提下，逐步具备独立设计、开发、测试、部署和维护 AI 应用系统的能力。
>
> 学习投入：每天约 2 小时，建议每周 6 天学习、1 天休息或补进度。48 周是路线规划，不是必须赶完的期限；某阶段未通过验收，就先补足再继续。

## 学习原则

- 项目驱动：每个阶段都围绕一个能运行、能展示、能解释的项目。
- 先基础后框架：先理解 Python、HTTP、数据库、模型和检索的基本原理，再使用高层框架。
- 理论与实践交替：学习一个概念，就在当前项目中实现或验证它。
- 先做小而完整的版本，再逐步增加功能。
- 数学按需补强：重点学习向量/矩阵、函数与导数、概率统计、梯度和优化，不追求脱离应用的数学堆砌。
- 中文为主、英文为辅：先用中文理解，再逐步阅读官方英文文档和项目 README。
- 工具不过度绑定：模型供应商、向量数据库和 Agent 框架都要理解接口与替代方案。

## 每日 2 小时建议节奏

- 10 分钟：回顾上次内容和待解决问题。
- 25 分钟：阅读课程或官方文档，理解一个核心概念。
- 65 分钟：围绕项目写代码、运行、测试和调试。
- 15 分钟：整理笔记、记录问题和结果。
- 5 分钟：写下下一次的第一个动作。

如果当天遇到难题，可把阅读时间转为调试时间；不要为了打卡牺牲理解。

## 阶段 1：Python 与开发基本功（第 1–6 周）

**目标：** 能独立编写结构清晰的 Python 程序，使用 Git 管理代码，理解 API 和基本调试方法。

| 周次 | 学习内容 | 项目任务与验收 |
|---|---|---|
| 1 | Python 安装与运行、变量、类型、输入输出、运算符、条件判断 | 完成个人信息程序、温度转换器和简单计算器；能解释每行代码 |
| 2 | for/while、字符串、列表、元组、字典、集合 | 做一个命令行待办清单，支持新增、查看和删除 |
| 3 | 函数、参数、返回值、作用域、模块、包、异常 | 把待办清单拆成函数和模块；为异常输入增加处理 |
| 4 | 文件读写、JSON、CSV、路径、日期时间、面向对象入门 | 将待办清单保存到 JSON 文件，重启后仍能读取 |
| 5 | pip、虚拟环境、依赖管理、调试器、日志、单元测试基础 | 为项目建立独立环境，编写基础测试和 README |
| 6 | Git 基本命令、分支概念、HTTP、REST API、请求与响应 | 完成“命令行学习助手”1.0：读取数据、调用一个公开 API、保存结果并提交 Git |

**主教材：**
- [Python-100-Days](https://github.com/jackfrued/Python-100-Days)
- [Python 官方教程（英文）](https://docs.python.org/3/tutorial/)

**阶段验收：**
- 不看教程也能写函数、循环、条件和常见数据结构；
- 能创建虚拟环境、安装依赖、运行程序；
- 能用 Git 查看状态、提交和同步；
- 能解释 HTTP 请求、JSON 和 API 的基本关系。

## 阶段 2：数学、数据处理与实验方法（第 7–10 周）

**目标：** 为机器学习建立够用的数学直觉和数据处理能力。

| 周次 | 学习内容 | 项目任务与验收 |

| 10 | 均值、方差、分布、概率、抽样、相关性与实验记录 | 完成一份可复现的数据分析报告，注明数据来源和限制 |

**主教材：**
- [NumPy 中文文档](https://numpy.org/doc/stable/user/absolute_beginners.html)
- [Pandas 用户指南](https://pandas.pydata.org/docs/user_guide/index.html)

**阶段验收：** 能加载、清洗、分析和可视化数据；能解释向量、矩阵、均值、方差、导数和梯度在模型训练中的直观意义。

## 阶段 3：机器学习（第 11–16 周）

**主教材：**

**阶段验收：** 能解释训练流程、数据泄漏、过拟合和主要分类指标；能独立训练、评估并保存一个基线模型。

- 能说明模型质量、成本、延迟和安全边界；
- 能独立定位至少一类真实故障并修复。

## 阶段验收规则

不要仅以“看完课程”作为通过标准。每阶段结束时，学习者需要：
- 用自己的话讲清核心概念；
- 不照抄地完成一个小功能；
- 运行并解释测试或实验结果；
- 说明已知限制和下一步改进；
- 将代码、说明和复现步骤保存到仓库。

如果未达到标准，允许增加复习周。理解和可复现能力优先于赶进度。

## 学习资源选择规则

- 每个阶段只指定一个主教材，其他资料作为查阅补充。
- 优先官方文档、维护活跃且有示例和练习的中文开源项目。
- 学习框架前先理解其解决的问题，不为追逐热门工具频繁换技术栈。
- 使用云端模型或第三方服务前，先确认网络可用性、数据处理方式和费用。
- MacBook 与 Windows 11 分别创建虚拟环境；通过 Git 同步源码和笔记，不同步环境目录、密钥和模型大文件。
