# 36 周 AI 全栈学习路线

## 阶段 1：Python 与开发基础（第 1–4 周）
- Python 语法、函数、模块、异常、文件与面向对象
- Git/GitHub、命令行、虚拟环境、API 与 JSON
- NumPy、Pandas 和基础数据可视化
- 验收：独立完成一个命令行工具和一个小型数据分析
- 主教材：[Python-100-Days](https://github.com/jackfrued/Python-100-Days)

## 阶段 2：数学补充与机器学习（第 5–8 周）
- 向量、矩阵、导数、梯度、概率与统计
- 回归、分类、决策树、集成学习、聚类
- 训练/验证/测试集、过拟合与评估指标
- 验收：完成一个端到端机器学习项目
- 主教材：[南瓜书](https://github.com/datawhalechina/pumpkin-book)

## 阶段 3：深度学习（第 9–14 周）
- PyTorch 张量、自动求导、训练循环
- 神经网络、CNN、序列模型、Attention、Transformer
- 优化器、正则化、训练与验证
- 验收：训练并解释一个模型，手写简化 Attention
- 主教材：[动手学深度学习](https://github.com/d2l-ai/d2l-zh)

## 阶段 4：大语言模型原理（第 15–20 周）
- Tokenizer、Embedding、Transformer 与 GPT
- Prompt、推理、上下文窗口
- 微调、LoRA、量化的基本概念与实践
- 验收：运行一个小型语言模型实验并构建聊天原型
- 主教材：[Happy-LLM](https://github.com/datawhalechina/happy-llm)

## 阶段 5：LLM 应用与 RAG（第 21–26 周）
- 模型 API、结构化输出、流式响应
- FastAPI、Embedding、向量检索
- RAG 数据处理、召回、重排、评估
- 验收：完成可运行的个人知识库问答应用
- 主教材：[LLM Universe](https://github.com/datawhalechina/llm-universe)

## 阶段 6：Agent 与工具生态（第 27–31 周）
- Tool Calling、Memory、规划与执行
- Agent 工作流、LangGraph、MCP
- 可靠性、权限边界与评估
- 验收：完成一个能调用工具的研究助手
- 主教材：[Hello-Agents](https://github.com/datawhalechina/hello-agents)

## 阶段 7：工程化与部署（第 32–36 周）
- Linux、Docker、环境变量与配置管理
- 服务部署、日志、监控、测试
- 安全、成本、性能与质量评估
- 验收：部署一个可访问、可维护的 AI 应用
- 参考：[Self-LLM](https://github.com/datawhalechina/self-llm)

## 每周验收标准
1. 能用自己的话解释本周核心概念。
2. 能运行并读懂至少一个真实项目示例。
3. 能独立修改或实现一个小功能。
4. 有学习记录和 Git 提交。
5. 能列出尚未解决的问题。
